# Comece por aqui

Esta pasta é o seu vault: cada arquivo `.md` é um nó da teia. Você pode editar aqui, na interface web ou em qualquer editor (inclusive o Obsidian).

## Como escrever na Teia
- Link simples: `[[Java]]` liga duas notas (relação padrão: relaciona-se-com).
- Relação tipada: uma linha `utiliza:: [[PostgreSQL]]` diz **como** as notas se relacionam.
- Um `✦` no fim da linha marca a relação como criada por IA.
- Proveniência no frontmatter: `source`, `confidence` e `verified`.
- Links para notas que ainda não existem aparecem como nós pendentes.
